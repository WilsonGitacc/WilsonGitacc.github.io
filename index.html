02 // Practical Discovery (Sanitized)

A Simple Real-World Finding: One-Line IDOR

Security vulnerabilities do not always require complex exploits. Below is a sanitized walkthrough of a production Broken Object Level Authorization (IDOR / CWE-639) finding I responsibly disclosed.

High • CWE-639 (IDOR)

How Changing One JSON Field Exposed Another Student's GPA

In an illustrative API pattern based on my disclosures, a grade-lookup endpoint accepted a valid student session JWT in the Authorization header, but looked up which student's record to return using the client-supplied student_id field in the request body. Because the server never checked whether the token owner matched student_id, any authenticated user could query another student's term_gpa and cumulative_gpa in read-only mode.

Second Illustrative Case Study: Broken Function Level Authorization (BFLA • CWE-862 • Medium)

In a separate catalog API pattern (endpoints fictionalized), POST /api/v1/catalog/reference/update properly rejected anonymous requests and malformed/alg:none JWTs, yet omitted the staff role check present on its sibling endpoint /api/v1/catalog/taxonomy/update (which returned 401 Unauthorized). Any authenticated low-privilege Guest token could invoke create, update, and delete handlers on shared reference dictionaries. Verified safely using a single synthetic record (TEST_REF_01) and restored immediately to baseline.

03 // University Project • Secure Programming (COMP6695001)

Designing a Safe LMS (OWASP ASVS Level 2)

A security-first university Learning Management System engineered with PHP 8.5.12 + Apache 2.4.69 + MySQL 8.4.13 LTS in hardened Docker containers to eliminate IDOR, SQLi, CSRF, and lateral database movement by design.

View GitHub Repo

Central Policy Gate & RBAC

Every request flows through a single front controller (public/index.php) enforcing deny-by-default role checks across Student, Lecturer, and Operator roles, strict BOLA/IDOR ownership filters, and constant-time CSRF validation (hash_equals).

  • Deny-by-Default
  • BOLA Prevention
  • Nonce CSP

Cryptography & DB Least Privilege

Passwords are hashed with Argon2id (memory_cost=65536, time_cost=4) alongside TOTP 2FA and session revocation. Queries use native PDO prepared statements (ATTR_EMULATE_PREPARES = false) via a DML-only DB user (lms_app) over 31 3NF tables with immutable audit triggers.

  • Argon2id + TOTP
  • PDO Prepared
  • Audit Triggers

Docker Network & Rootfs Hardening

The web container runs as unprivileged www-data (uid=33:33) with read_only: true, cap_drop: [ALL], and no-new-privileges: true. MySQL sits on an isolated internal: true backend network with port 3306 completely unpublished to the host.

  • read_only Rootfs
  • cap_drop ALL
  • Internal DB Net
